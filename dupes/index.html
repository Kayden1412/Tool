What counts as a duplicate? Two or more notes that share the selected key. “Expression + reading” keeps different readings apart; “Expression only” groups them; “Exact note row” only matches rows where every field is identical.

How it works

05
1

Export your notes

In Anki: Browse → select notes → Export → Notes in Plain Text. Keep the separator as tab. You can export different decks or batches as separate files.

2

Add one or many files

Drop several exports at once, or add them one by one. Each file is parsed locally and its expression/reading columns are auto-detected. Remove a file any time to rescan.

3

Review and export

See which keys repeat, where every copy lives, and how many notes are redundant. Filter across-file duplicates and download the report as CSV.

Blank readings: “Expression + reading” keeps a note with no reading separate from one with a reading. If your exports disagree about readings, switch to “Expression only”.

Privacy: files are read with browser APIs only. No network requests carry your notes, and nothing is installed or uploaded.
